## О проекте

В репозитории представлена курсовая работа по дисциплине «Объектно-ориентированное программирование». Реализована система управления базой данных магазина техники на языке **C++** с использованием библиотеки **MFC** (Microsoft Foundation Classes) и технологии **DLL** (Dynamic Link Library).

**Цель работы:** реализация системы управления базой данных магазина техники, позволяющей фиксировать поступление товара на склад с сохранением наименования, стоимости, количества и производителя.

**Объект исследования:** база данных магазина техники.  
**Предмет исследования:** объектно-ориентированная реализация системы управления товарным учётом.

---

## Задачи проекта

1. Изучить среду разработки Visual Studio и язык программирования C++.
2. Освоить принципы объектно-ориентированного программирования (ООП).
3. Изучить библиотеку MFC для создания графических интерфейсов.
4. Спроектировать полиморфную иерархию классов для товаров.
5. Реализовать операции добавления, сортировки, поиска и управления записями.
6. Вынести функциональность в отдельную DLL-библиотеку.
7. Реализовать проверку утечек памяти.

## Функциональные возможности

Приложение предоставляет пользователю следующие возможности:

| Функция | Описание |
|---|---|
| **Показать всё** | Вывод списка всех записей из базы данных |
| **Показать утечки** | Проверка программы на наличие утечек памяти |
| **Количество товаров** | Подсчёт общего числа товаров в базе |
| **Сортировка** | Сортировка списка товаров по алфавиту |
| **Реверсировать** | Вывод списка в обратном порядке |
| **Поменять местами** | Обмен двух записей по их порядковым номерам |
| **Добавить** | Добавление новой записи о товаре |

Данные хранятся в текстовом файле `Items.txt` в формате CSV. При каждом изменении базы данных файл автоматически обновляется.

### Объектно-ориентированная модель

Реализована полиморфная иерархия классов:

```text
Item (базовый класс)
 ├── Name: string
 ├── Price: double
 ├── Amount: int
 ├── virtual GetTextOut()
 └── virtual GetTextFile()
       │
       └── Tech (наследник)
             ├── Producer: string
             ├── GetTextOut()
             └── GetTextFile()
```

Класс **`DataBase`** обеспечивает управление хранилищем:

```text
DataBase
 ├── vector<Item*> All                       // основное хранилище товаров
 ├── map<string, set<Item*>> TypesAndItems   // ассоциативное хранилище
 ├── set<string> Types                       // множество типов
 ├── ReadFile()                              // чтение из файла
 ├── WriteFile()                             // запись в файл
 ├── Add(...)                                // перегруженный метод добавления
 ├── ShowAll()                               // вывод всех записей
 ├── Sort()                                  // сортировка
 ├── Reverse()                               // реверс
 └── Swap(int, int)                          // обмен записей
```

### Реализованные принципы ООП

- **Инкапсуляция** — данные и методы объединены в классах, доступ к полям осуществляется через публичные методы.
- **Наследование** — класс `Tech` наследует свойства и методы класса `Item`.
- **Полиморфизм** — виртуальные методы `GetTextOut()` и `GetTextFile()` переопределяются в дочернем классе.
- **Абстракция** — общие характеристики товара выделены в базовый класс `Item`.

### DLL-библиотека

Вся функциональность вынесена в отдельную DLL. Экспортируемые функции:

```cpp
DLL_API void UpdateFile();
DLL_API string ShowAll();
DLL_API string CheckMemory();
DLL_API string GetCount();
DLL_API bool Reverse();
DLL_API bool Sort();
DLL_API bool Swap(int a, int b);
DLL_API void Add(string Title, double price, int amount);
DLL_API void Add(string Title, double price, int amount, string producer);
DLL_API void Delete(int a);
```

## Интерфейс приложения

Основное окно программы содержит:

- **Левая панель** — кнопки управления (Показать всё, Показать утечки, Количество товаров, Сортировка, Реверсировать, Поменять местами).
- **Центральная панель** — поля ввода для добавления нового товара (название, цена, количество, производитель).
- **Правая панель** — многострочное поле вывода с вертикальной прокруткой.
